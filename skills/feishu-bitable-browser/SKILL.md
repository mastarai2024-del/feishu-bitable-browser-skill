# 飞书多维表格网页登录

Skill 不携带账号授权。使用本人正常网页会话；账号需对目标资源具有相应访问、编辑、下载权限。

## 入口

- 新电脑、缺少工具或登录过期时读 [setup.md](references/setup.md)。已有可用会话直接读取目标，避免重复登录。
- 已安装 EGO Lite 的 macOS 优先使用 ego-browser Skill，读取当前环境提供的入口。Windows、macOS 和支持的 Linux 可用随附 Playwright runtime；已有可用浏览器工具也可遵循同一流程。
- 打开用户给的实际链接，确认页面类型、标题及当前数据表。源电子表格、Wiki、Base 与 table ID 不混用；不同浏览器登录态独立。

## 读取与范围

读出任务涉及的字段类型、选项、稳定记录 ID 与完整记录数。Canvas 缺少行文本时使用正常导出或当前应用模型；固定页数、默认limit和截图不能证明读全。

写前保存旧字段定义、目标记录与旧值到私有任务目录。检查已有自动化是否会因这些改动触发未获授权的消息或动作；会触发时解释具体影响，取得针对性授权。普通“整理表格”不包含修改权限、公开分享、发消息或付费调用。

创建 Base/数据表时按用户给定内容操作界面，取得真实 URL/ID 并回读字段、记录。用户要空模板时保持空；不默认补 mock 数据。一般字段、视图、记录操作沿正常界面或已有明确授权的官方工具执行。

源表分组对应分类字段时读 [mapping.md](references/mapping.md)。按真实合并区确定归属，唯一匹配标题与完整描述，歧义单列。原选项保留，只补缺失选项和真正变化的记录。

随附自动helper聚焦现有单选分类字段；创建Base、其它字段类型、视图、权限和工作流仍走正常UI，不宣称完整API兼容。使用网页模型适配器前读 [adapter.md](references/adapter.md)。

## 写入与验收

1. 写前重读当前字段、内容与旧值；并发变化使计划失效时重新匹配。
2. 按用户已明确要求的范围执行普通写入，无需反复确认同一项。删除、权限、分享、消息和付费动作各需明确授权。
3. 批量任务先试写一条，等待正常保存并刷新确认后再处理其余；只发送所需字段。
4. 同步结束后刷新或重新读取服务器结果，逐条验证预期值、记录数、原选项和无关字段。前端新值、命令成功和截图存在不能单独算完成。
5. 超时、断开、部分保存或结果未知时保留回执，先核对已提交对象。不要直接重跑整份apply或按次数盲重试。

页面结构变化导致适配器不可用时停止，使用普通UI检查并定向适配；保持原有权限校验、同步与持久化机制。

交付实际目标链接及新增/更新/未完成数量。回读未通过的项目标为未完成。恢复只还原本次旧值，先排除后续用户修改；新选项有新引用时保留。

关闭本任务的源/临时页，保留用户原有页面；成果页需要继续查看时可保留。登录profile、任务XLSX、快照、截图和回执留在本机私有目录，不收入公开仓库。
